> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Extend Archerfish with schema-based validation, sample rate conversion, new waveform types (pulse, ASK, FSK, AM/FM/PM), waveform sidecar metadata, improved reporting, scenario dry-run, and additional impairments.

- Plan model: `ChannelBinding`, `TimelineEvent`, `RenderInstruction` with `resample_ratio` field
- Reporting: `Report`, `Metrics`, `RunDirectory` for output management

```cpp
#pragma once
#include <complex>
#include <cstddef>
#include <vector>
#include <cstdint>

namespace archerfish::dsp {

struct ResampleRatio {
    int numerator;
    int denominator;
    // Exact double ratio = numerator / denominator
    [[nodiscard]] double as_double() const { return static_cast<double>(numerator) / denominator; }
};

class ResamplerBlock {
public:
    /// Construct with rational resampling ratio.
    explicit ResamplerBlock(ResampleRatio ratio);
    ~ResamplerBlock();

    /// Process in-place: input buffer is consumed, output is resized.
    /// Returns output sample count.
    size_t process(const std::complex<float>* in, size_t in_count,
                   std::vector<std::complex<float>>& out);

    /// Compute the rational ratio for source_rate -> target_rate.
    [[nodiscard]] static ResampleRatio compute_ratio(double source_rate, double target_rate);

private:
    ResampleRatio ratio_;
    struct State; // pimpl for libsamplerate state
    std::unique_ptr<State> state_;
};

} // namespace archerfish::dsp
```

**Step 3:** Implement `resampler.cpp`:
- `compute_ratio()`: find integer L/M such that L/M approximates target/source using continued fraction expansion with a max denominator cap (e.g. 10000)
- `process()`: deinterleave I/Q to real buffers, run `src_simple()` (or `src_process()` for streaming) on each, reinterleave. Use `SRC_SINC_MEDIUM_QUALITY` converter.

**Step 4:** Write `tests/unit/test_resampler.cpp`:
- Test identity ratio (1:1) produces identical output
- Test 2:1 upsampling doubles sample count
- Test 1:2 downsampling halves sample count
- Test rational ratio (e.g. 44100 -> 48000 = 160:147)
- Test `compute_ratio()` returns exact ratio for integer cases

**Step 5:** Build and test. Commit: `feat: ResamplerBlock wrapping libsamplerate`
